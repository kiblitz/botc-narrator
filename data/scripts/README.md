Script definitions in the standard Blood on the Clocktower script JSON format
(a `_meta` entry followed by official character ids), fetched from
https://www.botcscriptorium.com on 2026-10-20.

`trouble_brewing.json` is the base edition, written by hand. A script is
playable once listed in `script::SCRIPTS` and every character id is in the
`characters::all()` registry.
